# himatika-docs

Situs dokumentasi **HIMATIKA** — Himpunan Mahasiswa Informatika ITSNU Pekalongan.

## Isi Dokumentasi

Dokumentasi ditulis dalam Markdown di folder `content/`:

- `1.getting-started` — pengenalan dan mulai memakai platform HIMATIKA
- `2.panduan-anggota` — panduan untuk anggota
- `3.panduan-tamu` — panduan untuk tamu/pengunjung
- `4.panduan-admin` — panduan untuk admin
- `5.panduan-agenda` — panduan seputar agenda

## Tech Stack

Nuxt 4, `@nuxt/content` 3, Docus, Nuxt UI, Tailwind CSS 4, `better-sqlite3`, `nuxt-llms`.

## Cara Menjalankan

```bash
npm install
npm run dev    # nuxt dev --extends docus
npm run build  # nuxt build --extends docus
```

## Repo Terkait

- [himatika-pdf-worker](https://github.com/iamdayy/himatika-pdf-worker) — service PDF / Excel / QR untuk HIMATIKA
