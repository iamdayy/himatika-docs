# Integrasi PDF Worker

Sebagai layanan mandiri (Microservice) yang di-deploy terpisah, **Himatika PDF Worker** menangani seluruh beban berat modifikasi *binary* seperti stempel tanda tangan, overlay QR Code, dan _rendering_ tiket.

## Arsitektur

- **Framework**: Python Flask.
- **Transport**: JSON via REST API.
- **Autentikasi**: JWT (JSON Web Token). Token ditandatangani menggunakan `JWT_SECRET` yang sama dengan aplikasi utama, dengan klaim khusus `{service: "himatika-backend"}`. Aplikasi utama melakukan sign di `server/utils/himatikaPdfWorker.ts` dan mengirimkan token melalui header `Authorization: Bearer <Token>`.

## Endpoint Tersedia

Seluruh request wajib mencantumkan Header `Authorization: Bearer <Token>`.

| Endpoint | Fungsi |
|:---|:---|
| `POST /api/pdf/ticket` | Generate tiket agenda (PDF) dengan QR Code |
| `POST /api/pdf/scan-qr` | Scan & decode QR Code dari file PDF |
| `POST /api/pdf/search-text` | Cari teks dalam PDF (untuk posisi TTD) |
| `POST /api/pdf/activiness-letter` | Generate Surat Keterangan Aktif |
| `POST /api/pdf/certificate-preview` | Preview template sertifikat |
| `POST /api/pdf/certificate` | Generate sertifikat final (dengan QR validasi) |
| `POST /api/sign/process` | Overlay tanda tangan digital QR ke PDF |
| `POST /api/sheet/export` | Export data ke file Excel (.xlsx) |
| `POST /api/sheet/import` | Import data dari file Excel |
| `POST /api/tools/qr` | Generate QR Code (base64) |
| `POST /api/tools/compress-image` | Kompresi gambar (JPEG) |
| `POST /api/tools/upload-image` | Upload gambar ke R2 Storage |
| `POST /api/media/compress-video` | Kompresi video |

## Keamanan

### SSRF Guard

Semua request keluar dari PDF Worker melewati **SSRF guard** (`utils/fetch_guard.py`) yang memblokir permintaan ke alamat IP lokal, private, atau rentan SSRF. Request dengan target tidak valid akan ditolak dengan status 400.

### Timeout

Request eksternal (misalnya pengambilan file dari R2) menggunakan timeout ketat untuk mencegah blocking tanpa batas pada worker.

### R2 Key Sanitization

Upload file ke Cloudflare R2 menggunakan sanitasi nama file (`utils/storage.py`) untuk mencegah path traversal dan memastikan key aman.

### PDF Ticket QR Signing

PDF tiket yang dihasilkan menggunakan **HMAC-signed QR** (`server/utils/qrToken.ts`). QR berisi payload `{a, h, p, t: "pdf"}` yang ditandatangani dengan secret terpisah. Signature yang tidak valid akan ditolak saat proses check-in.

## Spesifikasi Custom PDF (AgendaModel)

Aplikasi utama mengandalkan konfigurasi *layout* tiket yang bisa diubah admin. Parameter ini dipassing di dalam body `POST /api/pdf/ticket`:
- `pdfWidth`, `pdfHeight` : Dimensi dokumen E-Ticket.
- `signers`, `signatureItemId` : Koordinat (x,y) dan meta-informasi penandatangan.
- `fontSize`, `fontWeight`, `fontFamily` : Tipografi _custom_ untuk mencetak nama peserta.

## Manajemen Memori

Pekerja PDF (`pdf-worker`) sangat memori intensif. Ekosistem secara paksa menegakkan pendekatan *Context Manager* (`with open()`) di Python agar setiap _file descriptor_ ditutup begitu respon dikembalikan ke Nuxt (menghindari _memory leak_ di lingkungan Vercel Serverless).
